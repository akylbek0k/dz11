# 📹 WebRTC Video Interview 1-on-1 — Платформа для видеособеседований (ДЗ №11)

Домашнее задание: веб-приложение для проведения технических видеособеседований 1 на 1 в реальном времени с использованием технологии **WebRTC**, сигнального сервера на **WebSocket** и автоматическим деплоем на **GitHub Pages** через **GitHub Actions**.

- 🌐 **Демо (GitHub Pages):** [https://akylbek0k.github.io/dz11/](https://akylbek0k.github.io/dz11/)
- ⚡ **Signaling WebSocket Server:** `wss://inai-col3.fishrungames.com/signaling/`
- 🎯 **STUN Сервер:** `stun:stun.l.google.com:19302`

---

## 🚀 Возможности и Особенности

### 1. Видеосвязь WebRTC в реальном времени (P2P)
- **Direct P2P Streaming:** аудио и видео передаются напрямую между собеседниками с минимальной задержкой.
- **Интерактивные элементы управления медиа:**
  - 🎤 Включение / отключение микрофона (`audioTrack.enabled = !enabled`).
  - 📷 Включение / отключение камеры (`videoTrack.enabled = !enabled`).
  - 🖥️ **Демонстрация экрана (Screen Sharing)**: замена видеотрека на экран собеседника в 1 клик для демонстрации кода, слайдов или резюме.
  - 🔀 **Переключение режимов отображения**:
    - **Картинка в картинке (PiP)**: собеседник на весь экран, ваше видео в плавающем окне в углу.
    - **Раздельный вид 50/50**: два равных окна рядом (Split View), как в Zoom / Google Meet.
  - ⏱️ **Таймер собеседования**: автоматический отсчет продолжительности активного звонка.

### 2. Сигнальный протокол (`wss://inai-col3.fishrungames.com/signaling/`)
- При подключении участник отправляет `{ type: 'ready' }`.
- Сервер гарантирует одновременное подключение максимум двоих участников (при подключении третьего первый выбивается).
- Обмен сессиями:
  1. Создание и отправка **Offer** (`RTCSessionDescriptionInit`).
  2. Прием оффера, создание и отправка **Answer**.
  3. Обмен **ICE Candidates** (`RTCIceCandidateInit`) для установки NAT-соединения через STUN.
- Обработка отключения: при разрыве соединения оставшийся участник получает `{ type: 'peer-left' }`, интерфейс корректно сбрасывает удаленный поток и переходит в режим ожидания нового подключения.

### 3. Инструменты для собеседования (Interview Toolkit)
- 📝 **Онлайн-редактор кода / заметок**:
  - Совместное написание кода с синхронизацией в реальном времени через WebRTC DataChannel и WebSocket.
  - Готовые шаблоны задач: Two Sum (JavaScript), Проверка на палиндром (Python), SQL-запросы, Чистый лист.
  - Быстрое копирование кода.
- 💬 **Встроенный чат звонка**: отправка текстовых сообщений, ссылок и подсказок прямо во время видеозвонка.
- ℹ️ **WebRTC Диагностика**: мониторинг статуса WebSocket signaling, состояния ICE-соединения и адресов серверов.

### 4. Удобное тестирование
- В шапке сайта предусмотрена кнопка **«Тест во 2-м окне»**, которая открывает второе окно браузера с правильными пропорциями для мгновенной проверки звонка самому себе в соответствии с заданием.

## 🛠 Стек технологий

- **React 18** + **TypeScript**
- **WebRTC API** (`RTCPeerConnection`, `MediaStream`, `RTCDataChannel`, `getDisplayMedia`)
- **Native WebSocket API** (Signaling)
- **Vite** (сборщик с относительными путями `base: './'`)
- **GitHub Actions** (CI/CD пайплайн для автоматической публикации на GitHub Pages)

## 💻 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/akylbek0k/dz11.git
   cd dz11
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```

4. Откройте в браузере `http://localhost:3001`. Для проверки откройте вторую вкладку/окно или нажмите кнопку «Тест во 2-м окне».
